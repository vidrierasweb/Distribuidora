# DistriOeste — Demo de sitio para distribuidora

Sitio web demostrativo desarrollado por **Vidrieras Web** para una distribuidora mayorista orientada a kioscos, almacenes y autoservicios.

## Características

- Diseño responsive pensado especialmente para celulares.
- Presentación de categorías de productos.
- Armador de pedidos con cantidades y total estimado.
- Preparación del pedido para enviarlo por WhatsApp.
- Secciones informativas sobre entregas, ventajas y preguntas frecuentes.
- Animaciones e interfaz interactiva.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Demo online

https://vidrierasweb.github.io/Distribuidora/

## Importante

Este proyecto es una demostración de diseño web. El nombre comercial, los productos, los precios, las condiciones de entrega y demás datos son ilustrativos y deben verificarse y personalizarse antes de usar el sitio en un negocio real. También hay que revisar y configurar los datos de contacto y WhatsApp.
